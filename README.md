## 平台简介

- 本仓库为前端技术栈 [Vue3](https://v3.cn.vuejs.org) + [TS](https://www.typescriptlang.org/) + [Element Plus](https://element-plus.org/zh-CN) + [Vite](https://cn.vitejs.dev) 版本。
- 成员项目: 基于 vben(ant-design-vue) 的前端项目 [ruoyi-plus-vben](https://gitee.com/dapppp/ruoyi-plus-vben)
- 成员项目: 基于 vben5(ant-design-vue) 的前端项目 [ruoyi-plus-vben5](https://gitee.com/dapppp/ruoyi-plus-vben5)
- 配套后端代码仓库地址
- [RuoYi-Vue-Plus 5.X(注意版本号)](https://gitee.com/dromara/RuoYi-Vue-Plus)
- [RuoYi-Cloud-Plus 2.X(注意版本号)](https://gitee.com/dromara/RuoYi-Cloud-Plus)

## 前端运行

```bash
# 克隆项目
git clone https://gitee.com/JavaLionLi/plus-ui.git

# 安装依赖
npm install --registry=https://registry.npmmirror.com

# 启动服务
npm run dev

# 构建生产环境
npm run build:prod

# 前端访问地址 http://localhost:80
```

# 太行视觉AI监控中心

## 项目简介

太行视觉AI监控中心是一个基于Vue3 + TypeScript + Element Plus开发的现代化监控平台，专为工业园区安全监控设计。该平台采用科技感十足的UI设计，实时展示各类预警信息、设备状态和安全事件，帮助管理人员快速响应和处理安全隐患。

## 主要功能

- **实时监控数据展示**：展示当前预警事件、设备状态和位置信息
- **预警趋势分析**：通过图表直观展示预警趋势变化
- **预警类型统计**：展示各类预警类型的数量和占比
- **预警等级占比**：通过饼图展示不同等级预警的分布情况
- **预警处理状态**：展示预警的处理情况（待处理、处理中、已完成）
- **3D地图可视化**：通过3D地图直观展示设备分布和预警位置
- **实时天气和位置信息**：集成高德地图API，展示实时天气和位置信息
- **预警记录管理**：展示详细的预警记录，包括事件、时间和处理状态
- **设备预警TOP榜**：展示预警数量最多的设备列表

## 技术特点

- **科技感UI设计**：采用深色主题，配合荧光色调和渐变效果，打造未来科技感
- **响应式布局**：适配不同屏幕尺寸，确保在各种设备上都有良好的显示效果
- **实时数据更新**：支持数据的实时刷新和更新
- **丰富的图表可视化**：使用ECharts实现多种图表展示，包括趋势图、饼图等
- **3D地图集成**：支持3D地图展示，提供更直观的空间感知
- **实时天气API集成**：集成高德地图API，获取实时天气信息
- **优化的动画效果**：添加适当的动画和过渡效果，提升用户体验

## 界面预览

- 整体监控大屏：科技感十足的监控中心界面，集中展示各类数据
- 预警记录表格：优化的表格设计，清晰展示预警记录
- 3D地图展示：带有网格背景和扫描线效果的3D地图
- 数据图表：精美的图表设计，直观展示数据趋势和分布

## 配置说明

### 天气API配置

本项目使用高德地图API获取实时天气数据，使用前需要配置API密钥：

1. 在高德开放平台申请API密钥
2. 在`src/views/visionAI/ivisualCenter/index.vue`文件中替换`your_amap_key_here`为您的实际API密钥

```javascript
const response = await axios.get('https://restapi.amap.com/v3/weather/weatherInfo', {
  params: {
    key: 'your_amap_key_here', // 替换为实际的API密钥
    city: '130100', // 石家庄市代码，可根据实际情况调整
    extensions: 'base',
    output: 'JSON'
  }
});
```
